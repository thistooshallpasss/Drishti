## 🌟 About Drishti

**Drishti** (*Sanskrit: दृष्टि — vision, clear perception, focus*) is a distraction-free personal command center designed to eliminate digital friction and bypass modern algorithmic home-feed traps.

### 🏛️ The 10 Focus Hubs

1. 🤖 **AI & Machine Learning**: ML, Deep Learning, Computer Vision, LLMs, Math for AI, RAG & Agents.
2. ⚡ **Coding & DSA**: Arrays, Trees & BST, Graphs, Dynamic Programming, Heaps & Tries.
3. 🏛️ **System Design**: Low Level Design (LLD), High Level Design (HLD), Distributed Systems & Architecture Case Studies.
4. 📡 **Recent Update in Market**: Curated ArXiv AI research papers, engineering blogs & tech news.
5. 🐙 **Open Source**: Trending AI repos, PR tracker, framework architecture reading.
6. 🕉️ **Life Sutras & Wisdom**: Bhagavad Gita reflections (BG 2.47), daily principles, mindset quotes.
7. ❤️ **Health & Energy**: Workout protocols, sleep optimization, nutrition, daily energy logs.
8. 💰 **Finance & Wealth**: Investment portfolio, monthly expense ledger, market watchlist, financial goals.
9. 💼 **Apply Job & Career**: Target companies pipeline, resume versions, interview prep logs.
10. 🛠️ **Tools & Deep Links**: Direct launchpad for AI tools (ChatGPT, Gemini, Claude), Google Docs, Gmail, Social & Comms, and Audio.

---

## 🚀 Key Features

- **🌲 Hierarchical Google Docs Tree (`1.`, `1.1`, `1.1.1`)**: Multi-level nesting with cascading deletions (deleting `1.1` removes all sub-topics).
- **📦 Below-Tree Document Cards**: Structured visual cards for every chapter note.
- **⚡ Active Recall Flashcards**: 3D interactive flip cards with code snippets and formula explanations.
- **🕒 Recent 10 Destinations Tracker**: Instant re-opening of your last 10 visited tools or doc notes.
- **📊 Activity Logging & CSV Exporter**: Daily, Weekly, and Monthly study logs exportable as CSV.
- **🎨 5 Visual Themes**: Obsidian OLED, Midnight Navy, Cyber Matrix, Sunset Warmth, Paper Light.
- **🔍 Global Spotlight Search (`⌘K`)**: Instant search across all 10 hubs, notes, and links.

## 🛠️ Local Setup

```bash
# Clone repository
git clone https://github.com/<YOUR_USERNAME>/Drishti.git
cd Drishti

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🚢 One-Click Deployment (Vercel)

1. Push this repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your `Drishti` repository.
4. Click **Deploy** — Vercel automatically detects Next.js!
